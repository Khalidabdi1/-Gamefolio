# Gamefolio development rules

- Build an Expo SDK 55 app with Expo Router, Expo UI (SwiftUI on iOS), and Uniwind.
- Reference: Bingers TV & Movie Tracker; adapt the supplied visual design to games.
- Preserve near-black surfaces, 2:3 covers, generous spacing, coral accents and native iOS glass.
- Commit every coherent change. Push after each completed task group. Never force-push.
- Read versioned Expo docs before changing native APIs.
- Verify TypeScript and web export; validate native UI with native-sim on iOS 26.
- Never describe web screenshots as verified native iOS output.
- Keep credentials and simulator access keys out of Git.
